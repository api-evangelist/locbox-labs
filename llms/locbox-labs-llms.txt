# LocBox Labs (Hownd, Inc.)

> LocBox Labs is the engineering identity behind Hownd, Inc. (formerly FetchRev, originally LocBox), a Tempe, Arizona automated promotions and local-merchant marketing platform. Hownd runs automated marketing for restaurants, health and beauty businesses, family entertainment centers, attractions and retail merchants across website popups, email drip and birthday campaigns, social media, buy-now promos, gift cards, a promo discovery portal, the MyHownd consumer mobile app, and guest-WiFi capture.

Generated by the API Evangelist enrichment pipeline on 2026-08-13. Hownd does not publish an llms.txt; this file is generated from the API Evangelist catalog entry and the artifacts in this repository. Every URL below was fetched and its status recorded.

## What an agent can and cannot do here

- There is **no OpenAPI, GraphQL SDL, AsyncAPI, MCP server or A2A agent card** for this provider. Probes of every base host, application host and marketing host missed.
- There **is** a real API: the **Hownd Partner API** at `https://partner-api.hownd.com`. It is not self-service. Client credentials and a per-merchant Tenant ID are issued by Hownd to approved partners, and the HTTP method and path for its one documented resource are not published.
- The only surface a merchant can integrate without talking to Hownd is a **per-account JavaScript popup embed**.

## APIs

- [Hownd Partner API](https://github.com/LocBoxLabs/hownd-examples): Secured REST API for approved partners to manage Subscribers on behalf of Hownd merchants. Base URL `https://partner-api.hownd.com`. OAuth 2.0 client-credentials bearer token from `https://hownd.auth0.com/oauth/token` with audience `https://partner-api.hownd.com`. Requires `Authorization: Bearer`, `Content-Type: application/json` and `X-Tenant-Id`. Server-to-server only.
